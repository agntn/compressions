Every row is `create(name).info()`, computed in your browser from the registry the CLI and the agent tools read. The ratio is the same few lines of text through each format at its default container and level, compressed right here. zstd and brotli have no ratio, since this package reads them and doesn't write them.

## Picking one

Reading something? Its format picked itself. [identify](/guide/identify) names it, and each format's page says what its containers keep in the header.

Writing for a person with a terminal? [gzip](/formats/deflate#gzip) opens everywhere. [xz](/formats/lzma#xz) is smaller and slower, and every Linux box has it too. [bzip2](/formats/bzip2) sits between them on text and loses to xz on almost everything else.

Writing for a program? [zlib](/formats/deflate#zlib) is the one every language reads without a dependency. [LZ4](/formats/lz4) when speed matters more than size.

Matching what somebody else wrote? Their format wins. zstd and brotli read here, they just don't write, since the tools that make them are a package install away.
