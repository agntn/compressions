The [playground](/playground) runs the library in this page. Compress, decompress, identify and list, with the same executors the MCP server runs.

Pick a tool, pick a format and a container, type. The answer shows up a moment after you stop. Underneath it you get the CLI line and the JSON a model would send for the same call, both ready to copy.

zstd and brotli are read only, so the playground starts them on a stream their own CLIs wrote. Decompress it, change a byte, watch the checksum complain.

## Every state is a link

The address bar follows the form. `?op=identify&data=H4sIAAAAAAAA/8tIzcnJVyjPL8pJUQQAbcK0AwwAAAA=` opens straight on that question. Add `peel=true` for nested layers, or `op=decompress&format=deflate&container=gzip` to open it. Share it, bookmark it, paste it into an issue.

## Nothing leaves the tab

No server reads what you paste. The blob from the puzzle you're stuck on stays with you.
